# Dino Phase 1 design direction

Status: implementation reference for Phase 1 review

## Character

Dino should feel clean, modern, athletic, strong, and approachable. The name is
the only explicit dinosaur reference. Do not add dinosaur imagery, mascots,
fossils, footprints, eggs, scales, or themed novelty icons.

## Structural reference

Ced's supplied education-app screenshots are approved only as structural
inspiration for:

- a modular card-based mobile dashboard;
- compact date navigation;
- visible progress and clear next actions; and
- a floating translucent bottom navigation bar.

Do not copy the classroom timeline, lesson terminology, chat promotion, rainbow
decoration, or 3D artwork.

## Role hierarchy

Athlete Home prioritizes today's workout, daily nutrition/recovery facts, and
weekly completion. Coach Home prioritizes athletes needing review and compact
weekly operating metrics.

## Visual system

- Warm off-white application background
- Opaque white cards
- Charcoal text
- One restrained green accent with pale supporting surfaces
- Semantic success, warning, and danger colors accompanied by text
- System typography
- Consistent 4–32 spacing scale
- Soft 18–20 px card radii
- Glass treatment limited to the floating navigation

The navigation must retain an opaque fallback when blur is unavailable or the
user enables reduced transparency.

## No-drift boundary

Phase 1 validates hierarchy, typography, spacing, card composition, and the tab
bar. It does not establish final branding, a logo, authentication screens,
workout logging forms, nutrition workflows, reports, or backend states.
